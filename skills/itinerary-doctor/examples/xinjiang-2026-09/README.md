# 案例：北疆秋色环线（2026-09-25 → 10-04）

这是一个**真实案例的完整留痕**：从一份用户自己排的行程表，到体检、重排、出交付物。

## 输入

- `input-行程v0.1.xlsx` —— 用户给的原始行程表（10 天，北疆环线）
- 约束：机票已出（9/25 到、10/4 返），9 晚酒店已订，
  其中 **9/27 白哈巴**那晚属稀缺资源（退了很难再订到）

原计划的后半段：赛里木湖 → 伊宁 → 那拉提草原 → 巴音布鲁克 → **独库公路**回乌鲁木齐。

## 体检发现的问题

| 问题 | 依据 |
|---|---|
| 9 月底—10 月初的**伊犁草原已过季**，"看草原"的预期会落空 | 该点位核心观赏窗口是 6—8 月绿草甸（`yili-steppe-season`） |
| **独库公路 2026 年昼通夜施**：只 8:00—19:00 放行，夜间全线封闭施工 | 新疆交通运输 / 新疆交警公告（`duku-window`） |
| **独库北段强制预约**：每日 0 点放第 7 天名额，一车一天限 1 次 | `duku-reservation-north` |
| **独库预计 10 月中旬冬季封闭**（大概率 10/10 前后），且可能提前 | `duku-season-close` |
| 原计划"6:30 出发走独库"**无效** —— 8 点才放行 | 同上 |
| **白哈巴自驾每日仅 200 台**，需提前一日在「原行网」抢，且逾期未取消会被禁止下次预约 | 喀纳斯景区管委会公告（`baihaba-vehicle-quota` / `-channel`） |
| 白哈巴还需**边防证** + **每日限流 3500 人** | `baihaba-document` / `-visitor-cap` |
| 喀纳斯/禾木**旺季私家车禁入**，观鱼台专线需单独预约 | `kanas-vehicle-ban` / `kanas-guanyutai` |

## 调整结果

- **砍掉伊犁段**（那拉提 / 巴音布鲁克 / 独库返程），**新增禾木**（正落在 9/15—10/5 的秋色窗口内）
- 把喀纳斯核心期排进 **9/28—9/30 工作日低谷**，避开中秋尾巴与国庆高峰
- 在"9 晚中 5 晚不动"的前提下给出退改决策：**只退被砍掉的 3 晚，克拉玛依那晚申请改期，新订 3 晚**

## 产出

| 文件 | 说明 |
|---|---|
| `output/路线图.html` | 单文件交互地图：按天配色、编号途经点、点日程聚焦、矢量/卫星切换 |
| `output/行程报告.md` | 退改决策表 + 避坑清单（带来源与核实日期）+ 逐日计划 + 待核实项 |
| `output/路线图.png` | 2600×3666 路线海报 |

## 怎么复现

`trip.json` 是**已经整理好的成品**（含真实路网几何），所以可以直接渲染、无需联网：

```bash
python scripts/render_html.py   trip.json -o output/路线图.html
python scripts/render_report.py trip.json -o output/行程报告.md
python scripts/render_poster.py trip.json -o output/路线图.png      # 需 Pillow
```

想验证**从原始表格出发**的第一步：

```bash
python scripts/parse_itinerary.py input-行程v0.1.xlsx -o /tmp/draft.json
# 会提示 D7/D8 的地名（伊宁/那拉提/巴音布鲁克）不在内置地名库里——
# 这是设计如此：库外地区必须现查现补，而不是猜
```

想验证路网与约束环节：

```bash
python scripts/fetch_routes.py     trip.json      # 重新拉 OSRM（会覆盖 trip.json，建议先备份）
python scripts/fetch_constraints.py trip.json     # 挂载约束库告警
```

## 已知的"不完全真实"之处

- 9/27—9/28 有两条互斥的走法：**方案 B**（车停贾登峪、全程区间车）是本文推荐并计入里程的那条；
  **方案 A**（自驾经哈巴河/铁热克提直进白哈巴）只作为备选画在图上，标了 `counts_toward_total: false`
  所以不计入总里程。两者只能走一条，取决于能否抢到每日 200 台的自驾名额。
- 里程来自 OSRM 计算；中国西部 OSM 路网不完整，交付前应人工核对关键路段。
