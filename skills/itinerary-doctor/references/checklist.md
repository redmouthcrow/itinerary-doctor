# 体检清单

体检一份行程时，按下面六类逐条过。每条都要落到具体日期/地点，不接受"一般注意"这种空话。

## 1. 时令（最容易出错、也最容易被忽略）

- [ ] 每个**以自然景观为核心卖点**的点位，它的观赏窗口是否覆盖行程日期？
      （草原看绿、秋叶看黄、胡杨看金、花海看花期、湖泊看封冻/解冻）
- [ ] 该点位在行程日期处于窗口的**早期 / 全盛 / 尾期**哪一段？尾期要提醒"可能已过"。
- [ ] 是否与当年的**物候预报**冲突？（如阿勒泰气象台的秋叶预报、各地花期的官方发布）
- [ ] 高海拔点位在行程日期是否可能降雪/封路？

> 反例（本项目真实案例）：9 月底—10 月初去伊犁"看草原"——草原的核心价值是 6—8 月的绿草甸，
> 10 月初已是金黄/焦糖色，"看草原"的预期会落空；但作为摄影题材仍然成立。
> 结论要写成"因为目标是 X，所以建议 Y"，而不是简单说"值/不值"。

## 2. 预约与配额（第二容易出错）

- [ ] 每个景区**是否实行实名预约/分时入园**？渠道是什么？
- [ ] 是否有**每日限流**？旺季是否常满？需要提前几天？
- [ ] 是否有**单独的二次预约**项？（如观鱼台专线、自驾车辆名额、日出/夜景时段）
- [ ] **自驾车辆**是否限量？停车在哪？是否需要提前登记车牌？
- [ ] 预约的**违约后果**是什么？（例如逾期未入园且未取消会被禁止下次预约）

## 3. 证件与准入

- [ ] 是否涉及**边境管理区**（需要边防证）？线上能否办？目的地怎么写？
- [ ] 是否涉及**保护区/军事区/林区防火期**的准入限制？
- [ ] 外籍/港澳台游客是否有额外限制？（如需旅行社接待、住宿备案）

## 4. 驾驶强度（用真实里程算，不用直觉）

- [ ] 每天**真实路网**驾驶里程与时长（含区间测速的现实折损）。
- [ ] 是否超过团队上限（默认 7 h/天，带老人小孩降到 5 h）？
- [ ] 是否存在"看着近、实际绕"的路段？（高山盘山路、需要翻达坂、或 OSM 缺路）
- [ ] 加油/充电：景点内部是否有站？是否需要进景区前加满？
- [ ] 是否有**夜间行车**风险？（新疆日落晚但山区夜路危险，且部分公路禁夜行）
- [ ] 租车限制：车型是否满足（7 座以下、轴距、车龄要求等）？

## 5. 停运与封闭

- [ ] 季节性封闭公路的**开放/封闭日期**（如独库公路的年度封闭窗口与每日通行时段）。
- [ ] 缆车、区间车、索道的**末班时间**（常见事故来源：按错误时刻表安排，导致被困）。
- [ ] 是否有时段限制（如"昼通夜施"，仅 8:00—19:00 放行）？

## 6. 节假日与人群

- [ ] 行程是否覆盖法定节假日？**哪天开始放假、哪天上班**（调休）？
- [ ] 假期前后哪几天反而是**工作日低谷**（人流/房价明显更低）？把核心景区排进低谷。
- [ ] 长假首尾的交通高峰对高速路段的影响。

---

## 输出要求

每条检查项落到 `days[].alerts` 时，必须带：

| 字段 | 要求 |
|---|---|
| `text` | 具体到"哪个地方、什么限制、什么数字" |
| `source` | 官方来源名（政府公告 / 景区公众号 / 12328） |
| `verified_at` | 核实日期，用于判断时效 |
| `level` | `hard` 硬约束 / `soft` 参考 / `stale` 已过期待核实 |
| `impact` | 一句"所以行程要怎么改" |

**没有来源的条目不要写成确定语气。**
